# Crypto Investment Agent

בוט מסחר אוטומטי ל-Binance, עם ניהול סיכונים מובנה ומצב **Testnet** (כסף מדומה) כברירת מחדל.

> ⚠️ **קרא/י את סעיף "לפני שמריצים" למטה לפני שמחברים מפתחות API אמיתיים.**

## מה יש כאן

- **אסטרטגיה**: RSI מוגן ע"י מסנן מגמה (SMA) — קונה כשהמטבע "יקר מדי בירידה קצרה" בתוך מגמת עלייה, מוכר כשהמומנטום מוצה. פשוטה ומוסברת בכוונה, לא "קופסה שחורה".
- **ניהול סיכונים** (`risk_manager.py`) — כלל היציאה נבדק בסדר עדיפות הבא, הראשון שמתקיים מנצח:
  1. **מעגן-חירום בקריסה (Crash circuit-breaker)** — אם המחיר צונח 7%+ תוך שעה, מוכרים מיד, בלי לחכות ל-stop-loss הרגיל.
  2. **Stop-loss קשיח** — סגירת עסקה מפסידה ב--1.5% מנקודת הכניסה. הרשת הבטיחות הבסיסית של כל עסקה.
  3. **Trailing stop** — לאחר שהעסקה ברווח של +2% ומעלה, נפתח "עוקב" שממשיך לרוץ עם המחיר; אם המחיר נסוג 1.5% מהשיא שנרשם מאז הכניסה — מוכרים. כך רווחים גדולים לא נחתכים מוקדם מדי, אבל גם לא מפסידים חזרה את כל הרווח.
  4. **הגבלת זמן (Time-limit exit)** — עסקה שלא הגיעה לא ליעד ולא ל-stop-loss תוך 6 שעות (ברירת מחדל) נסגרת אוטומטית — למניעת הון "תקוע".
  - **הגבלת גודל פוזיציה** — לא כל היתרה בעסקה אחת (ברירת מחדל: עד 20% מהיתרה).
  - **מגבלת עסקאות ליום** — מונעת "ריצה חופשית" ומסחר יתר שאוכל עמלות.
  - **Kill-switch יומי** — אם ההפסד ביום עובר סף מסוים (ברירת מחדל: 5% מהיתרה), הבוט מפסיק לפתוח עסקאות חדשות עד למחר.
- **Testnet כברירת מחדל** — `USE_TESTNET=true` ב-`.env` גורם לבוט לרוץ מול [Binance Testnet](https://testnet.binance.vision/) עם כסף מדומה ונתוני שוק אמיתיים. כדי לעבור לכסף אמיתי צריך לשנות זאת **במפורש**.
- **Backtest** (`backtest.py`) — מריץ את האסטרטגיה על נתונים היסטוריים אמיתיים מ-Binance (ללא צורך במפתחות API) כדי לראות איך היא הייתה מתפקדת, לפני שמריצים בכלל.
- **לוגים** — כל החלטה, כל עסקה, כל שגיאה נכתבים ל-`logs/crypto_agent.log`.
- **בדיקות** (`tests/`) — הלוגיקה הפיננסית (ניהול סיכונים, אינדיקטורים) מכוסה ב-11 בדיקות יחידה.

## מבנה הפרויקט

```
main.py                        # נקודת הכניסה - מריץ את הבוט בלולאה
backtest.py                    # בודק את האסטרטגיה על נתונים היסטוריים
src/crypto_agent/
  config.py                    # טעינת הגדרות מ-.env
  exchange_client.py           # עטיפה סביב python-binance (Testnet/Live)
  indicators.py                # RSI, SMA (חישוב טהור, לבדיקה קלה)
  strategy.py                  # לוגיקת הקנייה/מכירה
  risk_manager.py              # stop-loss, take-profit, מגבלות יומיות
  state_store.py               # שמירת פוזיציה פתוחה בין הרצות
  trader.py                    # מחבר הכל יחד ומריץ את הלולאה
  logger_setup.py              # הגדרת לוגים
tests/                         # בדיקות יחידה (pytest)
.env.example                   # תבנית להגדרות - להעתיק ל-.env
```

## התקנה

```bash
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

## לפני שמריצים — סדר העבודה המומלץ

**שלב 1: Backtest (לא צריך שום מפתח API)**

```bash
python backtest.py --symbol BTCUSDT --interval 15m --days 30 --balance 400
```

בודק איך האסטרטגיה הייתה מתפקדת ב-30 הימים האחרונים. **חשוב**: זה לא ערובה לעתיד, זה רק כלי לבדוק שההיגיון לא שבור.

**שלב 2: Testnet (כסף מדומה, אבל מחירי שוק אמיתיים)**

1. הירשמי ל-https://testnet.binance.vision/ (חינם) וצרי מפתחות API.
2. שימי אותם ב-`.env` בתור `BINANCE_API_KEY` ו-`BINANCE_API_SECRET`.
3. וודאי ש-`USE_TESTNET=true` (זו ברירת המחדל).
4. הריצי:
   ```bash
   python main.py
   ```
5. **תני לזה לרוץ כמה ימים.** תסתכלי בלוגים (`logs/crypto_agent.log`), תוודאי שההתנהגות הגיונית, שאין באגים, ושהתוצאות סבירות.

**שלב 3: כסף אמיתי — רק אחרי ששלב 2 עבד כמו שצריך**

1. צרי מפתחות API אמיתיים ב-Binance (עם הרשאות Spot Trading בלבד — **בלי** הרשאת משיכה/Withdrawal!).
2. עדכני את `.env`: מפתחות אמיתיים + `USE_TESTNET=false`.
3. שקלי להתחיל עם סכום קטן מ-$400 בהתחלה, לא הכל בבת אחת.
4. הריצי `python main.py` — תופיע אזהרה גדולה ל-10 שניות לפני שהבוט מתחיל, בתור רשת ביטחון אחרונה.

## ⚠️ הגבלת רשת בסביבת הפיתוח הזו

הקוד נכתב ונבדק (11/11 בדיקות יחידה עוברות), אבל **הרצת `backtest.py` או `main.py` בפועל חסומה בסביבת הענן הזו** — יש כאן מדיניות רשת שלא מתירה גישה ל-`api.binance.com`. תצטרכי להריץ את הבוט מהמחשב האישי שלך (או שרת/VPS) עם גישה רגילה לאינטרנט.

## הגדרות עיקריות (`.env`)

| משתנה | ברירת מחדל | משמעות |
|---|---|---|
| `USE_TESTNET` | `true` | `false` = כסף אמיתי |
| `SYMBOL` | `BTCUSDT` | הזוג שנסחר |
| `INTERVAL` | `15m` | תדירות הנרות לניתוח |
| `MAX_POSITION_PCT` | `0.20` | אחוז מהיתרה שנכנס לעסקה אחת |
| `STOP_LOSS_PCT` | `0.015` | Stop-loss קשיח: סגירת עסקה מפסידה ב--1.5% |
| `TRAILING_ACTIVATION_PCT` | `0.02` | ה-trailing stop "נדלק" אחרי רווח של +2% |
| `TRAILING_DISTANCE_PCT` | `0.015` | מוכרים אם המחיר נסוג 1.5% מהשיא (אחרי הפעלה) |
| `MAX_HOLD_HOURS` | `6` | סוגרים עסקה "תקועה" אחרי כך וכך שעות |
| `CRASH_DROP_PCT` | `0.07` | מעגן-חירום: מוכרים מיד אם נפל 7%+... |
| `CRASH_WINDOW_MINUTES` | `60` | ...תוך חלון הזמן הזה (60 דק') |
| `MAX_DAILY_LOSS_PCT` | `0.05` | עצירת מסחר ליום אחרי הפסד של 5% |
| `MAX_TRADES_PER_DAY` | `6` | תקרת עסקאות ליום (נגד עמלות מיותרות) |
